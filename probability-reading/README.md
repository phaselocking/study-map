# 概率论 · 随课阅读

独立的轻量阅读试页，目前只覆盖 2026-10-29。先读四步主线，再按需要展开例题、中文讲义原文和补充说明。原档案馆与原始学习材料未修改。

`index.html` 是可直接打开、复制或下载的单文件，无需服务器、JavaScript 或网络。正文、公式样式和两张中文讲义片段已内嵌。数学公式在生成时用已有档案馆的 KaTeX 渲染。外部大学课程链接只作可选核对，打开这些链接需要网络。

## 更新

- `content.html`：编辑正文。`math-tex` 标签内写 TeX；加 `display="block"` 表示独立公式。
- `template.html`：单列排版与折叠样式。
- `assets/`：中文讲义原文片段。
- `build.cjs`：将公式与资源内嵌为单个 HTML。

本子项目与 `probability-atlas` 同级时运行：

```powershell
node build.cjs
```

也可以使用 `--archive` 指定旧档案馆目录，使用 `--output` 指定输出路径。无须安装依赖或修改原档案馆。
