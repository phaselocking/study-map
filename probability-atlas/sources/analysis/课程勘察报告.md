## 4. 老师怎样组织理解与解题

**先说“原来哪里不够用”，再引入新对象。** 第一章的概率是集合上的测量；10.8 `[00:05:09]` 至 `[00:16:44]` 反复谈抽象结果不便调用高数工具，所以引入随机变量。10.26 `[00:54:47]` 至 `[01:04:22]` 又沿着同样的映射、逆像思路进入二维。定义并不是孤立出现的。

**用模型建立联系，用直观预判，再回到公式。** 摸球贯通三类公式；几何分布和指数分布贯通离散、连续等待时间；泊松计数又连到指数间隔。10.12 `[00:57:53]` 明确要求先想结果再算。这种“直观”依赖独立、相同成功概率等题设，不能理解为凭日常感觉作答。

**解题的核心被放在事件和范围，而不是长计算。** 10.22 `[00:08:45]` 至 `[00:10:55]` 把困难定位在 `g(x)≤y` 对应的区域；10.26 `[00:01:33]` 至 `[00:04:35]` 强调判断单调性要限制到 X 实际取值区间。平方例题之所以反复出现，是为了比较同一个概率问题的不同求法与适用条件。
