# 单文件 HTML 阅读版

`probability-archive.html` 是档案馆的独立交付文件，可复制、下载后直接用浏览器打开，无需服务器或网络。

文件内包含课堂与知识点 JSON、全部逐段转录、来源 TXT／PDF／勘察报告副本，以及 KaTeX 脚本、样式和公式字体。当前快照为 11 节课堂、938 段转录，约 7.5 MB。课堂详情中的来源链接打开内嵌副本；未提供原始录音链接。

正常浏览器中支持时间线、知识索引、搜索筛选、数学公式和转录时间戳定位。部分手机文件预览器不运行 JavaScript；这种情况下仍显示全部课堂与逐段原文，公式以 TeX 文本展示，完整交互和附件打开功能需要浏览器支持脚本。

## 更新单文件

在项目目录运行：

```powershell
python scripts/build_standalone.py
```

该命令从当前 JSON、转录、来源副本和网页代码重新生成 `probability-archive.html`。文件是数据快照；修改数据后应重新生成。也可使用 `--output` 指定其他输出路径。
